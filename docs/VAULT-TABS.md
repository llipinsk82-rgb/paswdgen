# Podzakładki sejfu

Widok sejfu jest podzielony na trzy odrębne obszary:

- **Wpisy** — domyślny ekran z wyszukiwarką, licznikiem, dodawaniem oraz pełnowymiarową listą zapisanych usług.
- **Kopia** — ręczny eksport/import zaszyfrowanego pliku `.pgvault` oraz automatyczny backup do folderu wybranego przez użytkownika.
- **Migracja** — kontrolowany import i eksport CSV przeznaczony do migracji z lub do Google Password Manager.

Podział zapobiega zajmowaniu przestrzeni listy wpisów przez narzędzia kopii i migracji. Po przywróceniu wpisów aplikacja wraca do zakładki **Wpisy**, aby odzyskane pozycje były od razu widoczne.
